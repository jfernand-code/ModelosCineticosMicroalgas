# Modelos Cinéticos de Microalgas

Este proyecto es una calculadora interactiva para estimar la tasa de crecimiento ($\mu$) de microalgas utilizando diferentes modelos matemáticos.

## Modelos Implementados
* **Molina y cols.**: Basado en cinéticas sigmoidales.
* **Bannister**: Modelo versátil con exponente ajustable.
* **Camacho-Rubio**: Modelo avanzado para dinámicas de fotolimitación.

## Cómo usar
Simplemente abre `index.html` en cualquier navegador moderno.
